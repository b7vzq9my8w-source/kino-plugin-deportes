# Kino Deportes

Plugin de agenda y transmisiones deportivas para la aplicación oficial de Kino.

## Requisitos

- Kino 0.9.50 o posterior; se recomienda 0.9.54.
- Android System WebView actualizado para señales que necesiten captura.

## Instalar en Android TV

1. Abre Kino → Ajustes → Plugins.
2. Escribe `b7vzq9my8w-source/kino-plugin-deportes`.
3. Pulsa Agregar y acepta los hosts, el navegador oculto y la reproducción desde CDN.
4. Abre Deportes desde la barra lateral.

## Actualizar

Kino revisa una versión mayor del manifiesto periódicamente. También puedes usar Buscar actualización en Ajustes → Plugins.

## Diagnóstico

Activa Modo debug en Ajustes → Plugins → Kino Deportes y comparte el registro sin incluir cookies ni enlaces con tokens.
